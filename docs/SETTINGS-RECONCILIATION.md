## 专节：`glass=1` / `styles` 的疑问（**请你重点看这条**）

这是我**唯一无法自证**的地方，写清全部证据链，交你判断。

### 事实链（全部可复核）

1. **旧模板（10-01）**：25 个字段，`glass=0.8`，**不含** `styles` / `surface` 字样（已 grep 确认）
2. **我重建时**：只覆盖 A 类那 9 个字段，**没碰 `glass`、没碰 `styles`**
   ⇒ 那一刻写出的文件按老模板应是 `glass=0.8`、无 `styles`
3. **当前**：26 个字段，`glass=1`，且有 `styles={surface:0, preview:true, bubble:1}`
4. **插件的加载逻辑**（`client.js` L218-235）：
   ```js
   for (var k in STORE.state) if (k in saved) patch[k] = saved[k]
   STORE.set(patch)   // → 内部 save() → 整份 PUT 写回
   ```
   **不 merge DEFAULTS**：文件里没有的字段，保留 `STORE.state` 里的 DEFAULTS 值，
   然后 `set()` 触发 `save()`，把**整个 state（含 DEFAULTS）写回磁盘**。

### 由此推出的两个必然结论

- **`styles` 字段是重建之后长出来的**：老模板没有它 ⇒ 重建产物里没有 ⇒ 只能是插件写盘的。
- **其值不是 DEFAULTS**：`DEFAULTS.styles = {surface:0.30, preview:true, bubble:0.5}`，
  当前是 `{surface:0, preview:true, bubble:1}`；`DEFAULTS.glass = 0.8`，当前是 `1`。
  ⇒ **是被实际拖动过的值**（`surface` 拖到最左、`bubble` 拖到最右）。
