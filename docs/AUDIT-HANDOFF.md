## 四、`1e9f0f1` 修的两个真缺陷（均由覆盖审计挖出，都在产品路径上）

### 缺陷一：跨 DPI 比对**误报 70.81%**

真实 oracle 路径是"各自裁剪 → 交给归一化比对"。同一张图，基准 1.0x、当前 1.25x：

```
各自裁剪得 282×724 与 353×904（宽高比 0.38950 vs 0.39049 已不同）
再归一化 ⇒ diff=225973（70.81%）、maxΔ=88 —— 而两张图内容完全一样
```

根因：`resizePixels` 采样式 `sx=(x+0.5)*xRatio-0.5` 对两条路径给出不同相位
（0.799 vs 0.800，差 0.3 像素），加宽高各自 round 的比例漂移，在壁纸纹理这类高频区域
就是几十级色差。

**⇒ 我此前"跨 DPI 能比"的结论只对整图成立、对真实 oracle 路径不成立。更正。**

修法：新增 `compareStable()` —— **先把两张图归一到同一尺度、再各自裁剪**，两边经历完全
相同的一次重采样 + 相同的裁剪。同尺寸退回精确比（不重采样）。修后同场景 `diff=0`。

### 缺陷二：开工前预检**自己也会挂**

预检原先走普通 `readState`（CDP 超时 30s）。坏状态下页面 `await fetch` 连表达式自带的
`AbortController` 都不生效（请求把事件循环一起卡住），预检要挂满 30s 才崩 ——
**完全没起到"早点明确报错"的作用**（实测连"预检"那行都没打出来就超时）。
修法：预检自带 9s 超时并容忍超时，超时即判通道不可用、给出"重启浏览器"指引。

### 另留两条**方法学**警告（防后人用错测法得出假结论）

- 不能自己写放大函数造"另一台机器的图" —— 最近邻 vs 双线性对同源图差 **74%**
- 裁剪与缩放的**先后顺序不是同一个变换** —— 同源图两种顺序差 **58%**、maxΔ=50

### 10.2 读原设置失败后仍可能改设置（真缺陷）

`freezeRotation()` 首次 GET 失败返回 null，但之后仍调 `pinWallpaper()`，而它**自己又 GET 一次**
⇒ 若这次成功就会带 `autoOn=false` 写盘；还原阶段因"没有原值"返回 `skipped` ⇒ **exit=0**，
而用户的轮播已被关掉。**"没有原值"并不保证"没有写入"。**

修法：`pinWallpaper` 必须显式收到**已确认有效的原始设置**才允许写；两处调用点拿不到就抛错终止。
新增 `tools/verify-oracle-flow.mjs`（14 项，把真函数装进沙箱跑完整控制流），
含"读失败 → 钉图被拒且 **0 次 PUT**"与"有原值才允许写"的正反两面；
**变异测试**：撤掉守卫后套件失败（exit=1）。

### 10.3 03 的噪声源（三版才定准，前两版结论都被推翻）

| 版本 | 当时的结论 | 实际 |
|---|---|---|
| 一 | "抗锯齿抖动，是容差的必然代价" | ✗ 不是抗锯齿（同会话连截 diff=0） |
| 二 | "43MP 大图跨刷新重采样不稳" | 部分对（预览框确实如此）但**不是**主因 |
| 三 | **宿主对话框 3% 半透明 + 插件动画装饰层** | ✓ 实测坐实 |

- **宿主对话框半透明**：真实背景挂在 `.wCInkW_panel`（`[role="dialog"]` 的**父元素**）上，
  `rgba(48,26,32,0.97)`。我最初写的 `[role="dialog"]{background:...}` **毫无作用**
  （那只是个透明外壳）。铁证：对话框背后铺纯红 ⇒ 面板像素变 **137116 px**。
  修法：遍历对话框**及祖先**，按 computed alpha 把非插件（类名不含 `bga`）的半透明底色
  抬成同 RGB 不透明（实测 `opaqueFixed=18`）。
- **插件动画装饰层**：`bga-fly f1..f22` / `bga-star s1..s17` / `bga-meteor`，共 41 个元素、
  **30 个落在面板内**。实测停动画前连截两张 **diff=1608**、停后 **diff=0**。
  修法：注入 `[class*="bga"]{animation:none}` 冻结。

**代价如实写**：动画本身不再被像素回归覆盖（它根本无法被像素比较）；静态渲染
（布局/配色/文字/按钮）照常覆盖。动效正确性应靠功能验证。
**容差保持 0（严格逐字节）**，处理后连跑 6 次全部 3/3 diff=0。
