# 底图插件 · 验收约定（当前版本）

> 这份文件是**验收目标的真源**。审核方第十轮指出：此前双方都在逐条修补，
> 没有及早把"完整验收目标"固定下来 —— 于是"六次零差异"被当成了正确性证据，
> 而它其实只能证明**在当前条件下的重复性**。
>
> **收尾条件（唯一）**：
> 1. 当前版本满足下面固定的**功能与外观要求**；
> 2. 约定的**关键错误能被检出**（每项都有正常例 + 坏例，坏例必须失败）；
> 3. 验收结束后**完整恢复用户状态**。
>
> **六次零差异只算稳定性证据，不算正确性证据。**
> 只有约定范围全部通过、且剩余缺口明确列在"排除范围"里，才允许写"验收完成"。
> 原始基准已丢 ⇒ **历史等价无法证明**；本约定只用于验收**当前版本**。

## 一、四条固定规则

1. **外观目标固定。** 用明确的参考画面与设置定义"当前目标"；现有基准保留不动。
   新建基准必须记录**原因**与**相对上一份的变化**（写在 manifest 的 `why` 字段与提交信息里）。
2. **覆盖按"插件影响的输出"确定，不按类名。**
   插件会向宿主节点下发颜色/透明度/背景 token（`client.js` 的 `settingsSurfaceCss`、
   `applyTheme` 等）—— 这些宿主节点上的效果**也是覆盖对象**。
   "类名没有 bga 所以不是插件的"这种判断此前已被推翻过一次，不得再用。
3. **每项都必须有正常例和坏例。** 正常情况通过；**故意弄坏后必须失败**。
   比较范围减少、锚点丢失、覆盖不足，一律**报告出来**（非零退出），
   不允许继续宣称"完整一致"。
4. **报告与证据绑定。** 每次验收记录：实际运行版本、浏览器、视口 CSS 宽高、DPR、
   设置快照（字段数 + 关键值）、底图**完整路径**（cat/file）、比较范围（矩形/屏蔽框/
   实际比较像素数）、以及各项结果。**未测项目单列**，不得混在"通过"里。

## 三、当前已知的**排除范围**（不算通过，也不假装覆盖）

写"验收完成"之前，这些必须留在清单里：

1. **图库缩略图仍被屏蔽**（第 5 项的残留）。两块缩略图（CSS `[683,748,869,783]`、`[884,748,1071,783]`）
   的倍率**量不出来**（它们是 `<span>` + CSS 背景图，读不到 `naturalWidth`）⇒ 按保守规则屏蔽。
   **预览框本身已经不屏蔽**，所以"预览/缩放/焦点"这一类错误是覆盖到的；缩略图渲染本身仍看不见。
2. **主题/透明度只覆盖三个宿主表面，不是全部**。05/06 看宿主侧栏、07/08 看宿主主体表面
   `[data-composer-card]`、03/04 看宿主对话框面板与插件 UI。
   `--dsw-alias-bg-layer-2/3/4`（气泡、卡片、多选等）**没有单独锚点** ——
   它们只在上述表面里间接出现。要全覆盖得再给每类表面加锚点。
3. **01/02 只覆盖 orb 周围一条带**（CSS 228×75）。侧栏上方是宿主装饰 + 会话行
   "进行中"旋转指示器（宿主 SVG 动画），**不参与比较**。
4. **动效层被冻结**（`animation:none`）。动画本身无法用像素回归，靠功能验证。
5. **`glass` / `styles` / `imageFraming` 三个字段无法自证**。
6. **原始基准已丢** ⇒ 不能声称"重构在语义上等价"。
7. **一条基准只在它自己的 CSS 视口尺寸下对像素有效**（实测结论，写进约定而不是含糊过去）：
   底图是 `background-size: cover` ⇒ **视口尺寸一变底图就重新裁切**，露出底图的区域像素整体改变
   （实测侧栏带 **95.5%** 像素不同）。所以"换窗口尺寸"的验收方式是**每个尺寸各录一份基准**，
   而不是拿旧尺寸的基准硬比。**跨 DPR 可以沿用同一份基准**（CSS 视口不变 ⇒ cover 裁切不变，实测 8/8）。
   几何本身是可迁移的（锚点实测推导 + 布局契约），不可迁移的是**底图裁切后的像素**。
8. **只跑了 Chrome**；Edge 未跑（矩阵用 CDP Emulation 改视口/DPR，换成 Edge 只差浏览器本身）。

## 四、当前可用命令

```powershell
cd E:\dsh-plugins\dsh-bg-atelier-official

# 离线（无需浏览器，可在 CI 跑）
npm test                                    # 语法门禁 18/18 + 套件 20/20
node tools/verify-oracle-geometry.mjs        # 几何可迁移性 + 两条漏检的正/反例（29 项）
node tools/verify-oracle-entry.mjs           # 入口级真退出码（20 项，含假 CDP 服务器）
node tools/verify-oracle-flow.mjs            # 控制流（22 项，真函数装沙箱）
node tools/verify-oracle-restore.mjs         # 还原三态（38 项）
node tools/verify-we-source-async.mjs        # WeSource 异步语义（41 项）

# 真机（需 GUI 在 127.0.0.1:19387，浏览器停在 GUI）
node tools/make-marker-wallpaper.mjs           # 装"中等尺寸标记图"（04 状态要用）
node tools/visual-baseline.mjs capture <基准名>
node tools/visual-baseline.mjs compare <基准名>
node tools/visual-baseline.mjs selftest        # 用真实插件元素验证检出能力（15 项）
node tools/audit-oracle-coverage.mjs <基准名>   # 覆盖边界审计（当前 23 项）
node tools/make-marker-wallpaper.mjs --remove  # 验收后卸载标记图（恢复用户底图库）
node tools/verify-viewport-matrix.mjs           # 迁移适配真机矩阵（换窗口尺寸/DPR，8 项）
```

**04 状态（预览与取景）的前置**：`tools/make-marker-wallpaper.mjs` 会把
960×540 的确定性标记图装到用户底图目录的 `_验收标记图/` 分类下。
它是**用户可见的**（会出现在底图工坊的分类里）⇒ 按"验收后完整恢复用户状态"，
不需要时用 `--remove` 卸掉。状态本身在录制/比对各一次切换到这张图，**结束后由
`restoreRotation` 把 wallpaper/zoom/focus 一并写回原值**（已在真机验证）。
